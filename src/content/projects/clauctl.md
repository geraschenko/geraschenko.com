A CLI for orchestrating Claude agents: humans attach a terminal UI while agents and scripts get the full Claude Agent SDK control surface, including context surgery — rewinding a conversation or reshaping an agent's effective context down to hand-picked messages plus a summary. See [Controlling Claude's context window](/blog/claude-context/).
