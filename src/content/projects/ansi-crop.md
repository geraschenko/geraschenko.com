A Rust CLI and library that crops ANSI-styled text, such as `tmux capture-pane -e` output, to a rectangle of rows and columns while keeping its colours. By default it trims the blank margins. I used it to turn terminal snapshots into the text-based terminal captures in [Claude Code settings recommendations](/blog/claude-settings).
