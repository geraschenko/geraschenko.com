## Blog prose

Anton's voice is playful yet professional: direct, concrete, personal, a little irreverent. Every sentence carries a concrete point, closers and transitions included. When drafting or editing a post, propose the structure and a rough sketch; Anton supplies the voice.

## Visual changes

Anton has the page open and judges how it looks faster than any screenshot loop. Use a headless screenshot when it answers a specific question you've written down first (a measurement, whether a fix took effect). For questions of taste, build, say what to look at and ask Anton.

## Dev server

- `astro dev` loads `plugins/` (imported by `astro.config.mjs`) once: after editing a plugin, ask Anton to restart it.
- The clipboard API needs HTTPS or localhost, so copy buttons fail on a phone reaching the dev server over the LAN; test them on the deployed site.
